Feeder by feeder

Which parts of the grid lose power most?

WAPA's grid is divided into feeders: lines that leave a substation and serve a set of neighborhoods. When generation runs short, WAPA switches whole feeders off in turns, which is what a rotating outage is.

      How this was built

      An open archive, a live collector and one tested model

      From March to November 2026 VI Update saved WAPA's outage map every five minutes and published the full record as open data. This pipeline downloads that archive and checks its fingerprint, then keeps the record going by polling WAPA's map itself. Python lands both into a Parquet data lake, DuckDB and dbt rebuild every number on this page with tested SQL, and the rebuild is checked against VI Update's own published tables on every run. Names that could identify a household are withheld before anything is stored.

      1. 1Download VI Update's archive from Zenodo and verify it
      2. 2Poll WAPA's outage map (three times per run) and save its rotation schedule
      3. 3Load the lake into DuckDB and place each outage on the Census map
      4. 4Model and test with dbt, including the match to VI Update
      5. 5Export JSON for this page
      6. 6Open, update or close alert issues on GitHub
